## Не завершено

- фильтрация — на проверенной категории отдельный фильтр не отображается;
- пагинация — в категории только 3 товара, перехода между страницами нет;
- изменение количества и удаление товара — не выполнялись в этом прогоне;
- оформление заказа — не отправлялось;
- создание аккаунта и реальные данные — не использовались;
- мобильный viewport и второй браузер — недоступны в текущем окружении;
- API и база данных — требуют отдельного прогона.

## Вывод

Доступные публичные сценарии работают ожидаемо. Для завершения полного чек-листа нужны отдельные прогоны с тестовым аккаунтом, безопасными тестовыми данными, мобильным viewport и API-инструментами.
