# Test Plan — nopCommerce Demo Store

## 1. Цель

Проверить основные пользовательские сценарии демонстрационного интернет-магазина и убедиться, что пользователь может найти товар, изучить его, добавить в корзину и перейти к оформлению заказа.

## 2. Объект тестирования

- Сайт: https://demo.nopcommerce.com/
- Основные области: регистрация, каталог, поиск, карточка товара, корзина и оформление заказа.

## 3. Виды тестирования

- функциональное тестирование;
- позитивные и негативные проверки;
- UI-тестирование;
- smoke testing;
- проверка валидации форм;
- базовая проверка HTTP-запросов через DevTools;
- проверка отображения в desktop viewport.

## 4. Область проверки

### Включено

- регистрация и авторизация;
- категории и поиск;
- карточка товара;
- добавление товара в корзину;
- расчёт итоговой суммы;
- сортировка;
- обязательные поля и опции;
- основные элементы интерфейса.

### Не входит в текущий прогон

- реальная регистрация с личным email;
- оплата и завершение заказа;
- API и база данных;
- мобильные устройства;
- полноценная кроссбраузерная проверка;
- нагрузочное тестирование.

## 5. Тестовые данные

Используются только учебные данные. Реальные персональные и платёжные данные не применяются.

## 6. Критерии начала

- сайт доступен;
- основные страницы открываются;
- чек-лист и тест-кейсы подготовлены.

## 7. Критерии завершения

- выполнены доступные сценарии;
- результаты зафиксированы;
- найденные дефекты оформлены;
- ограничения и непроверенные области указаны в отчёте.
