# Evidence / Attachments

Здесь хранятся подтверждения результатов тестирования:

- скриншоты найденных дефектов;
- видео воспроизведения;
- изображения ожидаемого и фактического результата;
- дополнительные материалы из DevTools;
- экспортированные логи или ответы API.

## Правила именования

`BUG-001-product-description.png`  
`TC-WEB-004-search-result.png`  
`WEB-015-sorting-price.mp4`

Каждый файл должен быть связан с тест-кейсом или баг-репортом и иметь короткое понятное название.
