## Что не проверялось

- создание реального аккаунта;
- оформление и оплата заказа;
- отправка личных данных;
- кроссбраузерная проверка;
- проверка на мобильных устройствах;
- API и база данных.

## Вывод

Базовые публичные сценарии и валидация обязательных полей работают ожидаемо. Следующий шаг — оформить подробные тест-кейсы для регистрации, поиска и корзины, затем отдельно проверить оформление заказа на тестовых данных.
