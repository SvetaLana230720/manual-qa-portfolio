# Тестирование nopCommerce Demo Store

Учебный проект по тестированию демонстрационного интернет-магазина.

Сайт: https://demo.nopcommerce.com/

## Цель

Проверить основные пользовательские сценарии интернет-магазина: от регистрации и поиска товара до добавления в корзину и оформления заказа.
